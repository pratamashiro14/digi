## 📧 Email Configuration (Production)

Untuk production, pastikan email bisa terkirim:

### Option 1: Menggunakan Gmail SMTP
Edit `admin/forgot_password.php` dan `admin/reset_password.php`:
- Ganti `mail()` function dengan PHPMailer library
- Setup SMTP dengan Gmail credentials

### Option 2: Menggunakan Sendmail
Edit `php.ini`:
```
sendmail_path = "/usr/sbin/sendmail -t -i"
```

### Option 3: Konfigurasi XAMPP Email (Windows)
Edit `php.ini`:
```
[mail function]
SMTP = smtp.gmail.com
smtp_port = 587
sendmail_from = "noreply@digidesain.com"

; Atau bisa menggunakan provider lain seperti:
; SMTP = smtp.mailtrap.io
; smtp_port = 2525
```

## 🔒 Keamanan

- Token di-generate menggunakan `random_bytes()` (cryptographically secure)
- Token berlaku hanya 1 jam
- Password di-hash dengan BCRYPT (`password_hash()`)
- SQL Injection protection: input sudah difilter
- Token otomatis dihapus setelah berhasil reset password

## 🆘 Troubleshooting

| Masalah | Solusi |
|---------|--------|
| "Email tidak terdaftar" | Pastikan email ada di tabel `t_admin` |
| "Token tidak valid/kadaluarsa" | Token berlaku 1 jam, buat token baru |
| "Email tidak terkirim" | Normal di localhost, gunakan `test_password_reset.php` untuk testing |
| "Password tidak bisa login setelah reset" | Password hash support 3 format, ensure no errors di update |
| Link reset password error 404 | Pastikan file `reset_password.php` ada di folder `/admin/` |
