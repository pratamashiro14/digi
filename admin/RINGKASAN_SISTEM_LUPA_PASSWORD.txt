3. ✅ /admin/test_password_reset.php

   - Hanya bisa diakses admin yang sudah login
   - Useful untuk testing di localhost

4. ✅ /admin/create_table.php
   - Script auto-create tabel t_password_reset
   - Run sekali: http://localhost/xampp/digi/admin/create_table.php
   - Tabel akan dibuat jika belum ada

5. ✅ /admin/index.php [DIMODIFIKASI]
   - Link "Lupa Kata Sandi" sekarang aktif → forgot_password.php

💾 DATABASE
═══════════════════════════════════════════════════════════════════════════════

Tabel Baru: t_password_reset
Columns:
  - id INT PRIMARY KEY AUTO_INCREMENT
  - email VARCHAR(100) - Email admin yang request reset
  - token VARCHAR(255) UNIQUE - Token random 64-karakter
  - expiry DATETIME - Waktu token expired (1 jam)
  - created_at TIMESTAMP - Waktu token dibuat
  - INDEX idx_token, INDEX idx_email (untuk fast lookup)

🔐 KEAMANAN
═══════════════════════════════════════════════════════════════════════════════

✅ Token Generation:
   - random_bytes(32) → cryptographically secure
   - Hasil: 64-karakter hex string
   - Storage: VARCHAR(255) di database
   - Unique: UNIQUE constraint prevent duplikat

✅ Token Lifetime:
   - Expiry: 1 jam setelah dibuat
   - Auto-check: strtotime('+1 hour')
   - Validasi: expiry > NOW()
   - Cleanup: DELETE setelah reset berhasil

✅ Password Security:
   - Minimum: 6 karakter
   - Hash: password_hash() dengan BCRYPT
   - Verify: password_verify() saat login
   - Storage: Password lama tidak disimpan

✅ Data Protection:
   - Email input: filter_var() validation
   - HTML output: htmlspecialchars() escaping
   - Database: Prepared statement ready (bisa ditingkatkan)

⚙️  KONFIGURASI DASAR
═══════════════════════════════════════════════════════════════════════════════

Mengubah Waktu Expiry Token:
  File: /admin/forgot_password.php
  Baris: $expiry = date('Y-m-d H:i:s', strtotime('+1 hour'));
  Ubah: '+1 hour' → '+24 hours', '+3 hours', dll

Mengubah Password Minimum Length:
  File: /admin/reset_password.php
  Baris: elseif (strlen($password_baru) < 6)
  Ubah: angka 6 → 8, 10, dll

Mengubah Email Domain:
  File: /admin/forgot_password.php
  Baris: $reset_url = "http://localhost/xampp/digi/admin/reset_password.php?token=$token";
  Ubah: URL sesuai domain production

📧 EMAIL CONFIGURATION (UNTUK PRODUCTION)
═══════════════════════════════════════════════════════════════════════════════

Development (Localhost):
  ✅ Email tidak perlu terkirim real
  ✅ Gunakan test_password_reset.php untuk testing
  ✅ Lihat token & copy-paste link

Production (Live Domain):
  1. Setup SMTP di php.ini:
     SMTP = smtp.gmail.com
     smtp_port = 587
     sendmail_from = noreply@digidesain.com

  2. Atau gunakan PHPMailer:
     - composer require phpmailer/phpmailer
     - Replace mail() dengan PHPMailer

  3. Test dengan menjalankan forgot_password.php
     - Email seharusnya terkirim ke inbox admin
     - Klik link di email
     - Reset password
     - Login dengan password baru

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Table t_password_reset doesn't exist"
Solution: Jalankan http://localhost/xampp/digi/admin/create_table.php

Problem: "Email tidak terdaftar di sistem"
Solution: Pastikan email benar-benar ada di tabel t_admin (check phpMyAdmin)

Problem: "Token tidak valid atau sudah kadaluarsa"
Solution: Token berlaku 1 jam, buat token baru dari forgot_password.php

Problem: "Email tidak terkirim"
Solution: NORMAL di localhost! Gunakan test_password_reset.php untuk testing

Problem: Link "Lupa Kata Sandi" masih 404
Solution: Refresh browser (Ctrl+F5), atau pastikan forgot_password.php ada di /admin/

Problem: Password tidak bisa login setelah reset
Solution: Check error message, pastikan password > 6 karakter
