Token Security:
  ✅ Generate: random_bytes(32) → 64-char hex
  ✅ Unique: UNIQUE constraint di database
  ✅ Lifetime: 1 jam (auto-expire)
  ✅ Cleanup: Auto-delete setelah reset

Password Security:
  ✅ Hash: password_hash() dengan BCRYPT
  ✅ Verify: password_verify() saat login
  ✅ Minimum: 6 karakter
  ✅ Confirm: Validation password harus cocok

Database Security:
  ✅ Validation: Email filter_var() check
  ✅ Escaping: htmlspecialchars() saat echo
  ✅ Index: Fast lookup dengan idx_token, idx_email
