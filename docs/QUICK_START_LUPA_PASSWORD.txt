⚙️  KONFIGURASI (OPSIONAL)
═══════════════════════════════════════════════════════════════════════════════

Ubah Waktu Expiry Token (default: 1 jam):
  📄 File: /admin/forgot_password.php
  🔍 Cari: strtotime('+1 hour')
  ✏️  Ubah ke: strtotime('+24 hours') atau strtotime('+3 hours') dll

Ubah Minimum Password Length (default: 6):
  📄 File: /admin/reset_password.php
  🔍 Cari: strlen($password_baru) < 6
  ✏️  Ubah ke: strlen($password_baru) < 8 atau < 10 dll

📧 UNTUK PRODUCTION (EMAIL REAL)
═══════════════════════════════════════════════════════════════════════════════

Saat production, email perlu bisa terkirim real ke inbox admin.

Option 1: Setup SMTP di php.ini
   📄 File: php.ini
   ✏️  Setup:
       SMTP = smtp.gmail.com
       smtp_port = 587
       sendmail_from = noreply@denscreative.com
       
Option 2: Gunakan PHPMailer Library (Recommended)
   📄 File: /admin/forgot_password.php & reset_password.php
   ✏️  Replace: mail() function dengan PHPMailer
   📦 Install: composer require phpmailer/phpmailer

Option 3: Edit Email Config
   📄 File: /admin/forgot_password.php (line ~50)
   ✏️  Ubah:
       From: admin@denscreative.com
       Domain: http://localhost/xampp/digi/ → https://yourdomain.com/

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ "Table t_password_reset doesn't exist"
   ✅ Jalankan: http://localhost/xampp/digi/admin/create_table.php

❌ "Email tidak terdaftar di sistem"
   ✅ Pastikan email ada di tabel t_admin (cek phpMyAdmin)

❌ "Token tidak valid atau sudah kadaluarsa"
   ✅ Token hanya berlaku 1 jam, buat token baru

❌ "Email tidak terkirim" (localhost)
   ✅ NORMAL! Di localhost email tidak terkirim real
   ✅ Gunakan: test_password_reset.php untuk testing

❌ Link di halaman login masih error
   ✅ Refresh browser (Ctrl+F5 untuk clear cache)
   ✅ Pastikan file forgot_password.php ada di /admin/
