# 🔐 SISTEM LUPA PASSWORD - PANDUAN LENGKAP

## ✨ Fitur yang Dibuat

Sistem lupa password yang aman dengan fitur:
- ✅ Form input email
- ✅ Verifikasi email di database
- ✅ Generate token random 64-karakter dengan algoritma cryptographically secure
- ✅ Token berlaku 1 jam (auto expired)
- ✅ Kirim email dengan link reset
- ✅ Form reset password dengan validasi
- ✅ Password di-hash dengan BCRYPT
- ✅ Validasi password minimal 6 karakter
- ✅ Confirmasi password harus cocok
- ✅ Auto delete token setelah berhasil reset
- ✅ Testing page untuk development (tanpa email real)

## 🔒 KEAMANAN DETAIL

### Token Security
```
✅ Generate dengan random_bytes(32) - cryptographically secure
✅ Disimpan sebagai hex string 64 karakter
✅ Unique constraint di database (tidak bisa duplikat)
✅ Expiry time: 1 jam otomatis
✅ Auto-delete setelah berhasil reset
```

### Password Security
```
✅ Minimal 6 karakter
✅ Hash dengan password_hash() + BCRYPT
✅ Verifikasi dengan password_verify()
✅ Password lama tidak disimpan
✅ Harus input ulang untuk validasi
```

### Data Security
```
✅ Email input divalidasi dengan filter_var()
✅ Token di-escape saat di-echo (htmlspecialchars)
✅ Email di-escape saat di-echo (htmlspecialchars)
✅ SQL Injection: Vulnerable jika input tidak di-escape!
   TODO: Update dengan prepared statements (mysqli_prepare)
```

## ⚙️ KONFIGURASI

### Mengubah Waktu Expiry Token

Edit file `admin/forgot_password.php`, cari baris:
```php
$expiry = date('Y-m-d H:i:s', strtotime('+1 hour'));
```

Ubah `'+1 hour'` menjadi:
```php
'+24 hours'   // 24 jam
'+30 minutes' // 30 menit
'+3 hours'    // 3 jam
```

### Mengubah Password Requirements

Edit file `admin/reset_password.php`, cari baris validasi:
```php
elseif (strlen($password_baru) < 6) {
    $message = 'Password minimal 6 karakter!';
```

Ubah angka `6` menjadi requirement yang diinginkan.

### Mengubah URL Email

Edit file `admin/forgot_password.php`, cari baris:
```php
$reset_url = "http://localhost/xampp/digi/admin/reset_password.php?token=$token";
```

Ubah URL sesuai domain production:
```php
$reset_url = "https://denscreative.com/admin/reset_password.php?token=$token";
```

## 🆘 ERROR HANDLING

| Error Message | Penyebab | Solusi |
|---------------|----------|--------|
| "Email tidak valid!" | Format email salah | Input email dengan format: user@domain.com |
| "Email tidak terdaftar di sistem." | Email tidak ada di t_admin | Cek email benar-benar ada di database |
| "Email reset password telah dikirim!" | Success! Token sudah dibuat | Tunggu email atau buka test_password_reset.php |
| "Token tidak valid atau sudah kadaluarsa (1 jam)." | Token tidak ada / sudah lewat 1 jam | Buat token baru dari forgot_password.php |
| "Password tidak boleh kosong!" | Input password kosong | Isi form password |
| "Password tidak cocok!" | Password baru ≠ Ulangi password | Pastikan kedua input sama |
| "Password minimal 6 karakter!" | Password terlalu pendek | Gunakan password minimal 6 karakter |
| "Gagal mengupdate password." | Error database | Cek koneksi database, check permission |
| "Password berhasil diperbarui!" | Success! | Login dengan password baru |

## 📊 DATABASE SCHEMA

### Tabel: `t_password_reset`

```sql
CREATE TABLE t_password_reset (
    id INT PRIMARY KEY AUTO_INCREMENT,
    email VARCHAR(100) NOT NULL,
    token VARCHAR(255) NOT NULL UNIQUE,
    expiry DATETIME NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_token (token),
    INDEX idx_email (email)
);
```

**Field Explanation:**
- `id` - Primary key, auto-increment
- `email` - Email admin yang request reset (FK ke t_admin.email)
- `token` - Random token hex 64-karakter (UNIQUE)
- `expiry` - Waktu token expired (1 jam ke depan)
- `created_at` - Timestamp pembuatan record
- `idx_token` - Index untuk fast lookup token
- `idx_email` - Index untuk fast lookup email

**Example Data:**
```
id | email               | token                               | expiry              | created_at
1  | ghinsor@gmail.com   | a1b2c3d4e5f6...                    | 2024-01-03 15:00:00 | 2024-01-03 14:00:00
2  | admin@denscreative.com| f6e5d4c3b2a1...                    | 2024-01-03 16:30:00 | 2024-01-03 15:30:00
```

## 📞 SUPPORT & TROUBLESHOOTING

### Masalah: "Table t_password_reset doesn't exist"
**Solusi:**
1. Buka: http://localhost/xampp/digi/admin/create_table.php
2. Tunggu sampai ada pesan SUCCESS
3. Refresh page jika perlu

### Masalah: Email tidak terkirim
**Solusi (Development):**
- Normal di localhost, gunakan `test_password_reset.php` untuk testing

**Solusi (Production):**
- Setup SMTP di php.ini
- Atau gunakan PHPMailer library
- Test dengan `mail()` function ke test email dulu

### Masalah: "Forgot Password" link masih error
**Solusi:**
- Pastikan file `forgot_password.php` ada di `/admin/`
- Pastikan file `reset_password.php` ada di `/admin/`
- Refresh browser (clear cache)

### Masalah: Redirect error setelah reset password
**Solusi:**
- Pastikan file `index.php` ada di `/admin/`
- Update redirect URL sesuai dengan domain Anda
